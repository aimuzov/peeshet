## Правила

- Голос мой: черновик пишется по брифу `mcp__thinks__write_as_me` (register `longform`) и
  проходит `check_as_me` с оценкой от 90.
- Пост пишется в rich Markdown (Telegram Rich Messages), но разметка по рубрике:
  - девлог, релиз, мысль, неделя — обычные абзацы, без заголовков, жирного и буллетов;
  - разбор — статья: можно заголовки `##`, списки, таблицы, код, формулы.
- Фото стоят отдельным абзацем там, где нужны по смыслу: `![](tg://photo?id=p1 "подпись")`.
  Ключ `p1` выдаёт загрузка картинки в очередь.
- Эмодзи только из моей палитры (👋 ✅ ⏳ ❤ 😶 🎒), и чаще без них.
- Хэштег рубрики в последней строке, один на пост. Имя проекта пишем текстом, хэштег не нужен.
- Ссылки только на живые сайты и бота, ссылки на репозитории только в разборах.
- Факты берём из коммитов, changelog и моих слов. Не выдумываем цифры, планы и оценки.
- Картинки нужны для релизов и разборов. Девлог можно без картинки, лучше со скриншотом.
